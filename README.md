# 駿旺工務｜JWorks

駿旺建築工程有限公司專屬的工務管理試用程式。

## 開啟試用版

GitHub Pages 網址顯示於儲存庫右側的 About 及 Settings → Pages。

在右上角切換管理端、工人端及顧客端，可體驗保養工單、派工、到訪安排、相片回報及驗收。手機瀏覽會自動使用手機版面。工程分為保養、室內工程及機電工程。

管理端提供工人技能標籤、時間衝突提示及營運報表；顧客可提交保養工單、確認到訪時間及跟進驗收。

## 試用資料

試用資料及相片儲存在各自瀏覽器的 IndexedDB；重新整理後保留，同一瀏覽器的角色共用資料，不同裝置的資料獨立。此試用版沒有正式登入、共用資料庫或背景手機推播。清除此網站的瀏覽器資料後，會回到初始示範資料。

## 發佈

此儲存庫包含編譯後的試用版網站及操作說明。GitHub Pages 由主分支的 `/docs` 目錄發佈，並保留 `docs/.nojekyll`。
